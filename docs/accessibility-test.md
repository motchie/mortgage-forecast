# アクセシビリティ手動確認チェックリスト

このチェックリストは、実機のブラウザと普段利用しているスクリーンリーダーで確認するためのものです。
特定のスクリーンリーダーでの合格を示すものではありません。

## スクリーンリーダー

- ページタイトルから「住宅ローン予測ダッシュボード」と分かる
- 見出し移動（多くのスクリーンリーダーでは `H` キー）で、現在値、ローン、シナリオ、グラフ、感応度、検証状態、注意、根拠へ順に移動できる
- Combinedの現在残高と月返済額を、それぞれのラベルと対応づけて理解できる
- ローンが複数ある場合、それぞれのカードをlabelで区別できる
- Currentが現在金利継続の機械的ケース、Base・Higher・Stressが手動仮定だと理解できる
- 各シナリオの「モデル上の注意」を開き、未検証仮定へ到達できる
- グラフを利用せず「データ表を表示」から年・シナリオ・金額を理解できる
- 一定金利ごとの返済リスクを、背景色に頼らず「備考」の文章から理解できる
- 横スクロールが必要な表では、その案内が読み上げられる

## キーボード

- `Tab` / `Shift+Tab` のフォーカス順序が画面の読む順序と一致する
- 表示対象selectを矢印キーでCombined・各ローンへ変更できる
- 「データ表を表示」を `Enter` / `Space` で開閉できる
- detailsの「モデル上の注意」を `Enter` / `Space` で開閉できる
- 横長の表にフォーカスし、矢印キーまたは `Shift+マウスホイール` で局所スクロールできる
- すべての操作要素でフォーカス枠が見える

## 拡大・表示

- 320px、375px、390px、430px、768px、デスクトップ幅でページ全体に横スクロールがない
- デスクトップ200%拡大で内容の欠落や重なりがない
- 横スクロールは、必要な表の専用領域内だけに留まる
- Windowsハイコントラストモードで見出し、数値、警告、フォーカス枠を確認できる
- OSの「視差効果を減らす」を有効にしたとき、不要なアニメーションや滑らかなスクロールが止まる

自動axeテストの違反0件は補助的な結果であり、WCAG 2.2 AAへの完全な適合を保証しません。
